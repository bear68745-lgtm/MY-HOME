# My Home v1

รุ่นแรกของ My Home:
1. เลือกรูปวาดจากแกลลอรี่ หรือถ่ายรูป
2. กำหนดความกว้างและความยาวจริง
3. แสดงรูปต้นฉบับในกรอบ 2D ตามสัดส่วนกว้าง x ยาว พร้อมซูม/เลื่อนและแสดงขนาด

## วิธีเปิด
1. ติดตั้ง Flutter
2. แตกไฟล์โครงการ
3. เปิดโฟลเดอร์ `my_home` ใน Android Studio หรือ VS Code
4. รัน `flutter pub get`
5. รัน `flutter run`

## หมายเหตุสำคัญ
รุ่นนี้เป็น "ฐานที่ใช้งานได้" สำหรับ 3 ขั้นตอนแรก ยังไม่ได้อ้างว่าระบบอ่านผนัง/ประตู/หน้าต่างจากภาพด้วย AI แล้วแปลงเป็นเส้นเวกเตอร์อัตโนมัติ
ขั้นต่อไปจึงค่อยเพิ่มตัวอ่านแบบ โดยไม่ทำลายโครงสร้างรุ่นแรก
